# Project Overview

## Overview

The Coral Cloud Resorts Agentforce Service Agent project demonstrates the implementation of an enterprise conversational AI assistant using Salesforce Agentforce Builder.

The system was designed to provide customers with an intelligent, AI-powered customer service experience capable of:
- Explaining resort experiences
- Validating customer membership information
- Retrieving available sessions
- Creating bookings
- Supporting customers through embedded website messaging

This project combines conversational AI, Salesforce CRM integration, workflow automation, and Experience Cloud deployment into a complete enterprise AI workflow.

---

# Business Problem

Coral Cloud Resorts needed a scalable customer support solution capable of:
- Reducing manual booking support
- Automating repetitive customer interactions
- Improving response times
- Providing 24/7 digital assistance
- Streamlining booking workflows
- Integrating directly with Salesforce CRM records

Traditional support systems often require:
- Human agents for repetitive tasks
- Manual customer verification
- Manual booking management
- Separate customer support and CRM systems

The goal was to create a unified conversational AI workflow that automates these processes while maintaining security, customer validation, and workflow accuracy.

---

# Solution

The solution was implemented using Salesforce Agentforce Builder and supporting Salesforce technologies.

The final solution includes:
- A primary AI service agent
- Specialized AI subagents
- Salesforce Flow actions
- Embedded website messaging
- Experience Cloud deployment
- CRM-connected booking workflows

The AI assistant can:
1. Understand customer requests
2. Validate customer identity
3. Retrieve CRM data
4. Retrieve available sessions
5. Create booking records
6. Return conversational confirmations

# AI Reasoning and Guardrails

The AI system uses structured instructions to:
- Validate customers before actions
- Retrieve Salesforce data safely
- Execute workflows in correct sequence
- Prevent workflow errors
- Enforce conversational guardrails

Examples include:
- Membership verification required
- Salesforce IDs required for sessions
- Session selection required before booking
- Guest count required before reservation creation
