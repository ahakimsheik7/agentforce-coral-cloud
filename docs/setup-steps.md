# Complete Setup Guide — Coral Cloud Resorts Agentforce Service Agent

## Overview

This project demonstrates how to build and deploy a complete enterprise conversational AI assistant using Salesforce Agentforce Builder.

The AI agent helps Coral Cloud Resorts customers:
- Learn about resort experiences
- Validate customer information
- Retrieve available sessions
- Create bookings
- Interact through website messaging

Technologies used:
- Salesforce Agentforce Builder
- Salesforce Flow
- Experience Cloud
- Embedded Messaging
- Salesforce CRM
- GitHub
- VS Code
