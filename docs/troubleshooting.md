# Troubleshooting Guide

## Overview

This document outlines common issues encountered during the development and deployment of the Coral Cloud Resorts Agentforce Service Agent and the solutions used to resolve them.

The troubleshooting process covered:
- Agentforce Builder errors
- Action configuration issues
- AI instruction problems
- Flow routing issues
- Embedded Messaging deployment
- Experience Cloud integration
- Preview testing problems

---

# 1. Agent Not Activating

## Problem
The agent could not be activated after configuration changes.

Possible Symptoms:
- Commit Version fails
- Activation button disabled
- Validation errors displayed

---

## Cause
Common causes included:
- Missing action configuration
- Invalid AI instructions
- Incorrect action references
- Incomplete inputs or outputs
