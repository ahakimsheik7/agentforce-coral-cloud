# Coral Cloud Resorts — Agentforce Service Agent

## Overview

This project demonstrates a fully functional enterprise conversational AI assistant built using Salesforce Agentforce Builder.

The AI service agent helps customers:
- Learn about resort experiences
- Validate membership information
- Retrieve available sessions
- Create bookings
- Interact through embedded website messaging

The project showcases enterprise AI orchestration using Salesforce technologies, conversational AI workflows, CRM-integrated actions, and Experience Cloud deployment.

# AI Workflow Logic

The AI agent follows structured reasoning workflows to:
1. Validate customer identity
2. Retrieve experience details
3. Retrieve available sessions
4. Request session selection
5. Request guest count
6. Create booking records
7. Return confirmation responses

The project demonstrates:
- AI orchestration
- Action-based reasoning
- Conversational workflows
- AI guardrails
- CRM-integrated AI systems
